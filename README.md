## 📝 技術筆記
- **層級管理 (Depth)**：
    - 地圖、洞 (5) < 拼圖 (100) < 拖拽中的對象 (200) < 背包遮罩 (80) < **背包按鈕/文字 (1000)**。
    - 確保 UI 永遠不會被遊戲物件擋住。
- **Git 常用指令**：
    - `git add .` ：追蹤改動。
    - `git commit -m "備註"` ：建立存檔點。
    - `git push -u origin main` ：上傳雲端。
- **GitHub Pages**：
    - 已啟用網頁託管，可透過手機（H機）掃描 QR Code 直接測試實機手感。
