## 🛠️ 開發里程碑 (V3.7 階段達成)

### 1. 音訊系統強化 🔊
- [x] **持久播放**：實作 `pauseOnBlur = false`，切換視窗音樂不中斷。
- [x] **喚醒機制**：實作 `AudioContext.resume()`，解決瀏覽器自動播放限制。
- [x] **音量平衡**：設定 BGM (0.4) 與 SFX (1.0) 比例。

### 2. 視覺流金與 UI 規範 🌟
- [x] **流金感應開關**：完成「呼吸脈衝流金」，拼圖放置時隱藏，拿走或踢除時重新出現。
- [x] **拼圖規範**：包包內拼圖統一為「圓形」，僅在放置地圖後呈現特定遮罩形狀。
- [x] **邊界保護**：實作 `Phaser.Math.Clamp` 防止放大鏡與物件拖拽出鏡。

### 3. 架構與穩定性
- [x] **語法修正**：修復 `lensX` 重複宣告報錯，結構趨於穩定。
- [x] **動畫優化**：改採 `progress` 數值驅動法確保動畫在各環境流暢執行。

## 🧠 核心機制變更 (Upcoming Pivot)
為了增加遊戲挑戰性，下一階段將導入以下邏輯：
- **萬用插槽**：地圖空格改為 6 個通用插槽，不再鎖定特定拼圖。
- **拼圖池擴充**：拼圖總數增加至 10-15 個（含正確項與干擾項）。
- **身份驗證機制**：拼圖可放進任何空格，但僅「正確答案」吸附時會觸發 `sfx_snap` 音效。
- **資訊模糊化**：鑑定報告統一標題為「風獅爺鑑定報告」，不顯示地名，需由學生自行判斷。
