## 🛠️ 開發里程碑 (V3.6 階段達成)

### 1. 呼吸脈衝流金系統 (Reactive Golden Glow) 🌟
- [x] **動態實作**：捨棄遮罩，改用 `onUpdate` 實時繪製雙層弧線（橘金底 `0xffa500` + 純金芯 `0xffd700`）。
- [x] **視覺節奏**：1.0s 動態期（淡入 $\rightarrow$ 旋轉 $\rightarrow$ 淡出）+ 2.0s 靜止期，避免視覺疲勞。
- [x] **自動感應 (Hole-Glow Logic)**：
    - 拼圖吸附時，光環自動執行 `toggleHoleGlow` 淡出隱藏。
    - 拼圖移開或被擠掉時，光環感應座標空缺重新觸發。

### 2. UI/UX 深度優化
- [x] **背包系統調整**：圖示放大 200%，上移至 y: 620，解決文字與背景黑條重疊問題。
- [x] **視覺統一**：背包內拼圖強制改為「圓形」，提升 UI 整潔度。
- [x] **鑑定系統**：完成「左圖右文」古籍視窗，支援打字機效果與自動比例縮放 (`Math.min`)。
- [x] **邊界保護**：實作 `Phaser.Math.Clamp` 防止放大鏡與物件拖拽出鏡。

### 3. 技術重構與修復 (Troubleshooting)
- [x] **變數作用域**：修復 `lensX` 重複宣告報錯。
- [x] **動畫邏輯**：清理 `timeline` 錯誤嵌套，改採 `progress` 數值驅動法確保穩定度。
- [x] **環境部署**：完成 GitHub Pages 部署，支援手機/平板實機測試。
